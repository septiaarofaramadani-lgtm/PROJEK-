# Nama Project : Pencatatan keuangan sederhana
deskripsi : untuk mencatat dan memenejement keuangan,target pengguna anak" sekolah
            banyaknya anak yang masih bingung dalam mencatat dan mengelolah keuangan
Teknologi yang digunakan : mengunakan bahasa pemrograman HTML,JavaScript,CSS
panduan penguna: pengunan dapat memasukan dana yang di punya lalu mencatat setiap pengeluaran dengan jenis pengeluaran untuk kebutuhan seperti apa 
pemanfaatan AI : Mengunakan gemini contoh promt yang digunakan: saya ingin membuat website untuk mengelolah sistem keuangan cara kerja dari web tersebut adalah pengguna dapat memasukan pendapatan dan mencatat pengeluaran serta menyesuaikan kebutuhan apa saja yang di perlukan
